# Katy deep-cleaning interactive experience

Only the EN/ES Katy deep-cleaning pages use this design. New photo sequence uses three existing first-party La Roca images with a gentle scale/crossfade, manual image selection and pause/resume. This is a photo animation, not footage or an invented before/after. No external video or dependency is loaded. Promotion is a compact upper-right badge.

Four accessible room tabs preserve every task from the original page. Keyboard arrows/Home/End supported; roles, selected state and panel associations set progressively. Without JS all room task lists remain visible. Included fridge/oven/cabinet interiors and interior windows retained. Added buildup context, preparation and the PDF checklist. Source quote form now has name, phone and service with one deep-cleaning option.

Motion starts paused with reduced-motion preference, stops when the page becomes hidden and can be paused manually. CSS disables transitions/keyframes for reduced motion. Browser verified autoplay advancement, pause/manual image selection, room switching and arrow-key navigation; EN/ES mobile at 375px had no horizontal overflow. Isolated runtime checks verified reduced-motion startup, preference-change stop, panel switching and keyboard focus. Internal links/assets and JSON-LD parsed; original room task text compared unchanged. No live leads submitted.
